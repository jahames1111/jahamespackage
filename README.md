# jahamespackage

Custom-made Windows utilities for using a personal computer at school.

## Downloads

Download the latest release from the [Releases page](https://github.com/jahames1111/jahamespackage/releases).

## OPN

**OPN.exe** is a port of Psiphon for connecting to the internet. Use it only where permitted by your school or network administrator.

### Installation

1. Download and unzip `OPN.zip`.
2. Open the extracted folder.
3. Double-click `OPN.exe`.
4. When the connection window appears, click **Connect**.

Once running, OPN can be opened from the Windows widget menu.

## Clean Desktop

**cleandesktop.exe** removes duplicate Google Classroom and Google Drive shortcuts created when using a school-managed Chrome profile.

### Installation and use

1. Download `cleandesktop.exe`.
2. Double-click the file to run it.
3. The utility keeps one copy of each Google Drive and Google Classroom shortcut and removes duplicates.

### Manage or uninstall

Click the arrow in the bottom-right corner of the screen to open the widget menu. Then, right-click the Clean Desktop icon to open its context menu.

## YouTubeRedirecter 1.1-main

**YouTubeRedirecter.exe** is a lightweight Windows utility that runs in the background and redirects the organization-blocked YouTube account redirect that appears when opening Gmail or Canvas.

### Features

- Runs automatically in the background.
- Redirects the YouTube account redirect to the destination specified at the end of the URL.
- Lightweight and easy to run.
- Can be stopped, changed, or removed through the Windows widget menu.

### How to use

1. Download and run `YouTubeRedirecter.exe`.
2. Open YouTube or an app such as Gmail or Canvas in Chrome.
3. The utility redirects the YouTube account redirect to the intended destination instantly.
4. To stop or change the utility, open the widget menu and right-click the YouTubeRedirecter icon.

### Configuration

You can disable the utility from the context menu.
